# T28c notice delivery

Generated notice bundle is included at `/usr/share/doc/reforge/third-party-notices.txt` in control and runner images. Docs image serves same generated bytes at `/docs/third-party-notices.txt`, linked from Reference. `scripts/dependencies.py` writes docs copy from canonical output; committed source snapshots are checked against manifest SHA-256 values before generation.

This delivers the current inventory only. It does not establish complete image attribution, Alpine package/source notice closure, arm64 image coverage, or legal clearance. Those remain external release evidence and review requirements; T28c stays open.
