## Index and source checks

Retained official APK indexes match current installed package name, version, architecture, APK checksum, and source commit for control `16/16`, runner `28/28`, docs `41/68`, and PostgreSQL `52/52` APK rows. PostgreSQL inventory has one extra synthetic `.postgresql-rundeps` row without an APK checksum; it is excluded. These mutable-branch indexes do not prove which indexes were used during image builds. Captured index archives and hashes are in ignored `.local/t28c-attribution/apk-download/`.

## Result and remaining work

No new Alpine OS notice text was added. Current docs non-root image `/usr/share/licenses` contains five nginx/module `COPYRIGHT` files. Their hashes match retained notice-source snapshots (`4f72e2bccf0bcd839dd447ab6f359336f428caa1987a9afec2bc9ade5711658a` for nginx and three modules; `bf0746e75035cc2b9c3346feb08fd7aa414c088719c00e76734c6d7fe9c0647d` for njs). Those exact image texts are already in the project notice bundle. They cover those five package paths only. The other 159 actual APK rows have no package-owned license/notice path in selected runtime images; no local APK/source artifact supplied their source text. An absent path does not establish that no notice applies. No legal determination was made.

For release-grade closure, build each selected final image from pinned inputs while preserving its build-time signed APK indexes and exact `.apk` archives. Verify each installed record against its index and archive; retain source `APKBUILD` and source archive checksums; then extract applicable exact notice texts and map each package to bytes. Current mutable-branch indexes do not prove build-time inputs. The 27 docs rows above lack matching retained-index records; five nginx rows also lack a source-commit field. Retrieve exact historical evidence if available. Otherwise rebuild from a deliberately selected immutable base and capture package evidence during build; do not attribute existing bytes from unrelated current packages. Regenerate image notices, verify each image copy, and obtain release-owner/legal review.
