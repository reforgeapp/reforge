## Result and remaining work

No Alpine OS notice text was added from source recipes or unrelated current packages. Current signed index metadata and aports recipes do not establish that every historical `.apk` archive and applicable notice belongs to these image bytes. I rechecked current docs non-root image `/usr/share/licenses`: all five nginx/module `COPYRIGHT` files match retained notice-source hashes (`4f72e2bccf0bcd839dd447ab6f359336f428caa1987a9afec2bc9ade5711658a` for four files; `bf0746e75035cc2b9c3346feb08fd7aa414c088719c00e76734c6d7fe9c0647d` for njs). They cover those paths only, not the docs image's 68-package dependency closure. No legal determination was made.

For release-grade closure, build each selected final image from pinned inputs while preserving its signed APK indexes and exact `.apk` archives. Verify each installed record against its index and archive, retain source `APKBUILD` plus its checked source revision/checksums, then extract exact license/notice/copyright texts and map every package to those bytes. For the 27 docs rows above, retrieve and verify matching historical archives from a retained mirror or the exact source evidence. If unavailable, rebuild the docs image from a deliberately selected immutable base and capture its package evidence during the build; do not attribute the existing image from current unrelated package records. Then regenerate image notices, test all image copies, and require release owner/legal review.
