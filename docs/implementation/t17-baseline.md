# T17 Repository baseline

Repository detail loads a scoped persisted repair baseline, effective policy evidence, and current discovery findings. A baseline displays its pinned head, baseline, target, candidate, model, runner pool, and frozen commands, with a run deep link. Empty, stale, and unavailable evidence remain explicit; the view does not infer repository health from missing records.

Browser fixtures cover populated and empty baseline responses plus repository-scoped findings. They do not claim live repair acceptance.
